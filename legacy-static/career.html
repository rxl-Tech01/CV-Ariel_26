Portofolio Kompetensi & Perencanaan Karier

Arah Karier & Peta Kompetensi

Evaluasi kemampuan aktual saat ini, pemetaan kekuatan dan kelemahan (SWOT), alasan pemilihan profesi Network Automation Engineer, analisis kesenjangan kompetensi, serta rencana pengembangan 3–5 tahun ke depan.

01 / Evaluasi Diri

Analisis Kompetensi Saat Ini

Pemetaan objektif berdasarkan praktikum, proyek kuliah yang sudah dikerjakan, dan kursus sertifikasi yang telah diselesaikan.

Sebagai mahasiswa aktif D3 Teknologi Telekomunikasi di Telkom University (angkatan 2024), kompetensi teknis yang saya miliki saat ini berada pada tahap fondasi akademik dan proyek prototipe, yang terbagi ke dalam tiga area utama:

  • Jaringan & Telekomunikasi (Praktik Akademik & Fundamental): Telah mempraktikkan pengalamatan IPv4, subnetting, konfigurasi Inter-VLAN Routing (dot1Q), dan OSPF Area 0 dasar menggunakan Cisco CLI pada praktikum laboratorium, serta memahami konsep dasar jaringan akses serat optik (FTTX) dan materi kursus HCIA-Access V2.5.
  • Pemrograman Python & Layanan Backend (Hands-on Project): Telah mengimplementasikan REST API menggunakan Python Flask, manajemen transaksi dan migrasi skema SQLite, verifikasi autentikasi Bearer token dengan hmac.compare_digest, simulator pengujian HTTP terisolasi (simulator.py), serta pengujian unit otomatis (unittest dan Ruff) pada proyek Tugas Akhir QuotaNode.
  • Sistem IoT & Pengolahan Citra (Hands-on Project & Sedang Dikembangkan): Memiliki pengalaman memprogram mikrokontroler ESP32 (integrasi RFID, Keypad, dan Blynk pada Smart Door Lock), mengimplementasikan aplikasi klasifikasi citra LeafSense AI (MobileNetV2 & Flask), serta saat ini sedang mempelajari komunikasi serial UART AT Command dan USSD pada modul LTE A7670E.
02 / Pemetaan SWOT

Analisis SWOT

Identifikasi kondisi internal (kekuatan & kelemahan) dan faktor eksternal (peluang & tantangan) dalam mempersiapkan karier.

S Strengths (Kekuatan)

  • Memiliki kombinasi dasar jaringan telekomunikasi dengan pengalaman praktik membangun backend Python (Flask, SQLite, REST API).
  • Terbiasa menyusun pengujian kode otomatis (unittest) dan dokumentasi teknis repositori.
  • Memiliki 7 sertifikat pelatihan dasar di bidang jaringan akses, FTTX, keamanan siber, cloud, dan AI.

W Weaknesses (Kelemahan)

  • Belum memiliki pengalaman magang atau kerja di lingkungan operasional jaringan skala produksi.
  • Belum menguasai secara praktis pustaka spesifik otomasi jaringan seperti Netmiko, NAPALM, dan Ansible.
  • Integrasi perangkat keras ESP32 dengan modem A7670E pada Tugas Akhir masih dalam proses penyelesaian.

O Opportunities (Peluang)

  • Meningkatnya kebutuhan industri telekomunikasi, ISP, dan data center terhadap otomasi konfigurasi serta pemantauan jaringan.
  • Ketersediaan simulator jaringan dan container (Packet Tracer, GNS3, PNETLab, Docker) untuk membangun laboratorium mandiri tanpa perangkat fisik mahal.
  • Adanya program magang industri pada kurikulum vokasi Fakultas Ilmu Terapan, Telkom University.

T Threats (Tantangan)

  • Persaingan ketat antar lulusan baru di bidang teknik jaringan dan teknologi informasi.
  • Banyak posisi jaringan tingkat lanjut yang mensyaratkan sertifikasi profesional (seperti CCNA atau HCIA-Datacom) dan pengalaman praktis.
  • Perkembangan cepat teknologi infrastruktur cloud dan perkakas NetDevOps yang menuntut pembaruan kompetensi terus-menerus.
03 / Target Profesi

Tiga Opsi Karier & Alasan Pemilihan

Penentuan fokus profesi utama beserta dua jalur karier alternatif yang selaras dengan latar belakang studi D3 Teknologi Telekomunikasi.

Profesi Utama

1. Network Automation Engineer

Mengembangkan script Python, integrasi API, dan alur kerja otomatis untuk konfigurasi, pemeliharaan, serta pemantauan perangkat jaringan.

Opsi Karier 2

2. Network Operations / Network Engineer

Menangani operasional infrastruktur routing, switching, jaringan akses FTTX, pemantauan NOC, serta pemecahan masalah konektivitas.

Opsi Karier 3

3. IoT & Telemetry System Engineer

Merancang sistem gateway mikrokontroler, komunikasi data seluler/sensor, dan layanan backend untuk dashboard telemetri IoT.

Alasan Memilih Network Automation Engineer sebagai Profesi Utama

Profesi Network Automation Engineer dipilih karena berada tepat di titik temu tiga bidang yang saya pelajari: (1) kurikulum inti jaringan dan infrastruktur di D3 Teknologi Telekomunikasi, (2) pengalaman nyata membangun layanan backend, REST API, dan pengujian otomatis menggunakan bahasa Python pada proyek QuotaNode, serta (3) ketertarikan pada sistem pemantauan telemetri perangkat. Jalur ini memungkinkan saya memanfaatkan kemampuan pemrograman Python untuk meningkatkan efisiensi operasional jaringan tanpa meninggalkan latar belakang pendidikan telekomunikasi saya.

05 / Peta Jalan

Career Roadmap 3–5 Tahun

Tahapan realistis dari penyelesaian studi vokasi hingga mencapai peran Network Automation Engineer.

Tahun 1 (2026 – 2027) · Penyelesaian Studi & Magang Industri

Menuntaskan Tugas Akhir, Lulus D3, dan Memasuki Peran Entry-Level

Menyelesaikan integrasi perangkat keras ESP32 dan modul A7670E pada Tugas Akhir QuotaNode, membangun proyek portofolio awal otomasi jaringan berbasis Python (Netmiko/Paramiko), menjalani magang industri, dan memulai karier pada posisi Junior Network Engineer atau NOC Engineer.

Tahun 2 (2027 – 2028) · Penguatan Operasional & Scripting Jaringan

Junior Network Engineer dengan Fokus Otomasi Operasional

Memperdalam pengalaman operasional routing, switching, dan pemantauan jaringan produksi sambil menerapkan script Python untuk mengotomasi pekerjaan berulang seperti pencadangan konfigurasi dan pemeriksaan status perangkat. Mengambil sertifikasi jaringan tingkat asosiasi (CCNA atau HCIA-Datacom).

Tahun 3 (2028 – 2029) · Transisi Peran Penuh Waktu

Network Automation Engineer

Beralih ke posisi khusus otomasi jaringan: merancang dan memelihara Ansible Playbook, mengintegrasikan API perangkat jaringan (RESTCONF/NETCONF), serta membangun dashboard observabilitas dan validasi perubahan jaringan otomatis.

Tahun 4 – 5 (2029 – 2031) · Pengelolaan Skala Besar & NetDevOps

Mid-Level Network Automation & Infrastructure Engineer

Mengelola arsitektur otomasi jaringan berskala lebih luas dan lingkungan hybrid cloud, mengimplementasikan pipeline CI/CD untuk pengujian konfigurasi infrastruktur (Infrastructure as Code), serta berkontribusi dalam pengembangan standar teknis tim.

07 / Strategi & Evaluasi

Strategi Pengembangan & Evaluasi Berkala

Metode belajar yang diterapkan secara konsisten beserta jadwal peninjauan progres bulanan, semesteran, dan tahunan.

Strategi Pengembangan Kompetensi

  • Pembelajaran Berbasis Proyek: Mengubah materi yang dipelajari menjadi proyek fungsional kecil dan menyimpannya di GitHub agar progres teknis tercatat dengan bukti kode.
  • Pemanfaatan Laboratorium Virtual: Menggunakan simulator jaringan dan container Docker untuk mempraktikkan skenario konfigurasi tanpa bergantung pada ketersediaan perangkat fisik.
  • Disiplin Pengujian & Dokumentasi: Menerapkan kebiasaan menulis unit test (unittest) dan panduan penggunaan pada setiap proyek yang dikerjakan.
  • Pemanfaatan Modul Akademi Industri: Mengikuti materi terstruktur dari program kemitraan kampus seperti Cisco Networking Academy, Huawei ICT Academy, dan AWS Academy.

Evaluasi Karier Berkala

  • Evaluasi Bulanan: Meninjau progres penyelesaian tahapan Tugas Akhir QuotaNode, memeriksa konsistensi latihan pemrograman/jaringan di GitHub, dan mencatat kendala teknis yang belum terpecahkan.
  • Evaluasi Semesteran (Per 6 Bulan): Memperbarui tabel Competency Gap Analysis untuk menilai kompetensi mana yang sudah berpindah dari level Sedang Dikembangkan ke Hands-on Project, serta meninjau kesiapan CV untuk lamaran magang.
  • Evaluasi Tahunan: Meninjau kesesuaian capaian akademik, sertifikasi, dan posisi magang/kerja terhadap tahapan pada Career Roadmap 3–5 Tahun, lalu menyesuaikan target tahun berikutnya.
